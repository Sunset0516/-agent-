## 1. 项目概述

### 1.1 项目背景

当前求职市场中，求职者（尤其是寻找实习机会的学生）面临以下痛点：

- 简历内容不突出，难以通过 ATS（自动筛选系统）
- 岗位信息分散在多个平台，筛选成本高
- 投递后缺乏系统化跟踪，容易遗漏跟进时机
- 面试准备缺乏针对性，不知道该练什么
- 技能与岗位要求不匹配，不清楚该补什么

### 1.2 项目定位

本项目是一个**基于多 Agent 协作的智能求职助手平台**，通过多个专业化 Agent 的协同工作，为求职者提供从**简历优化 → 岗位匹配 → 投递跟踪 → 面试准备 → 技能提升**的全流程智能化服务。

### 1.3 项目目标

- **核心目标**：帮助用户高效找到合适的实习机会
- **技术目标**：展示多 Agent 协作架构的设计与实现能力
- **产品目标**：提供流畅、智能、可视化的求职体验

| 内容完整性 | 25% | 教育、技能、项目、经历是否齐全 |

| 量化描述 | 20% | 是否有数据化的成果描述 |

| 关键词覆盖 | 10% | 是否包含行业关键词 |

### 3.4 岗位推荐模块（岗位匹配 Agent）

#### 3.4.1 功能清单

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 岗位录入 | 手动录入或批量导入岗位信息 | P0 |
| 智能匹配 | 根据简历自动推荐匹配岗位 | P0 |
| 匹配度评分 | 展示岗位与简历的匹配度百分比 | P0 |
| 岗位筛选 | 按城市、薪资、公司类型筛选 | P1 |
| 岗位详情 | 展示岗位要求、职责、公司信息 | P0 |

#### 3.4.2 匹配算法

- **基于技能的匹配**：简历技能 ∩ 岗位要求技能，计算 Jaccard 相似度
- **基于语义的匹配**（进阶）：使用向量嵌入计算简历与岗位描述的语义相似度
- **综合评分**：技能匹配(50%) + 经验匹配(25%) + 教育背景(15%) + 地点匹配(10%)

#### 3.4.3 岗位数据结构

```json
{
  "id": "job_001",
  "title": "AI Agent 开发实习生",
  "company": "某某科技有限公司",

  "salary": "200-300/天",
  "type": "实习",
  "requirements": ["Python", "LLM", "Agent 框架", "良好的沟通能力"],
  "responsibilities": ["参与 Agent 系统开发", "优化 Prompt 工程"],
  "tags": ["AI", "Agent", "实习"],
```

## 4. Agent 设计

### 4.1 Agent 列表

| Agent 名称 | 职责 | 输入 | 输出 |
|-----------|------|------|------|
| ResumeAgent | 简历解析与评分 | 简历文本 | 结构化简历 + 评分 + 建议 |
| JobMatchAgent | 岗位匹配 | 简历数据 + 岗位库 | 推荐岗位列表 + 匹配度 |
| TrackAgent | 投递状态跟踪 | 投递记录 | 状态更新 + 提醒 |
| InterviewAgent | 模拟面试 | 岗位要求 | 面试题 + 评估报告 |
| SkillAgent | 技能分析 | 简历 + 岗位要求 | 技能差距 + 学习路径 |

### 4.2 Agent 协作流程

```
用户上传简历
    ↓
ResumeAgent 解析简历 → 输出结构化数据
    ↓
JobMatchAgent 匹配岗位 → 输出推荐列表
    ↓
用户选择岗位投递 → TrackAgent 跟踪状态
    ↓
SkillAgent 分析技能差距 → 推荐学习路径
    ↓
InterviewAgent 模拟面试 → 生成评估报告
```

### 4.3 Agent 通信机制

- **协调器模式**：中央 Orchestrator 负责分发任务、收集结果
- **消息格式**：JSON 结构化消息
- **异步处理**：耗时操作通过任务队列异步执行

## 5. 非功能需求

### 5.1 性能要求

| 指标 | 要求 |
|------|------|
| 页面加载时间 | < 2 秒 |
| API 响应时间 | < 500ms（不含 LLM 调用） |
| LLM 调用响应 | < 30 秒 |
| 并发用户 | 支持 50 并发 |

### 5.2 可用性要求

- 系统可用率 > 99%
- 支持本地部署，离线可用（除 LLM 调用外）
- 数据本地存储，保护用户隐私

### 5.3 兼容性要求

- 浏览器：Chrome、Edge、Firefox 最新版
- 屏幕：适配 1280px 及以上宽度
- 操作系统：Windows / macOS / Linux

### 5.4 安全要求

- 密码加密存储（bcrypt）
- JWT Token 认证
- 输入数据校验与防注入
- 敏感数据（简历）加密存储

| 投递跟踪 | 投递列表、状态管理、时间线 |
| 面试辅导 | 模拟面试界面、题库、历史记录 |
| 技能图谱 | 雷达图、差距分析、学习路径 |

### 9.3 交互原则

- 操作反馈：所有操作都有 Loading 状态和结果提示
- 实时更新：投递状态变化实时刷新
- 引导式：首次使用提供操作引导
- 响应式：适配不同屏幕尺寸

## 11. 风险评估

| 风险 | 影响 | 应对措施 |
|------|------|---------|
| LLM API 调用成本高 | 高 | 提供本地模型备选，限制调用次数 |
| LLM 响应不稳定 | 中 | 加入超时重试、缓存机制 |
| 简历解析准确率低 | 中 | 迭代优化 Prompt，支持人工修正 |
| 岗位数据获取困难 | 中 | 支持手动录入，预留爬虫接口 |
| 多 Agent 协作复杂 | 中 | 先实现单 Agent，逐步集成 |
